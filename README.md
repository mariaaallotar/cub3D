# cub3D

“Realistic” 3D graphical representation of the inside of a maze from a first-person perspective using raycasting. I did input parsing and [Léon Mercier](https://github.com/LeonMercier) did the visuals.

## Features

- free movement in map
- wall collisions
- user has control of map
  - size and form (but must be enclosed by walls)
  - textures (every wall has different texture (north, south, east, west))
  - player spawn position and orientation
